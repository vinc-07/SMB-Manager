# About
>This is a menu bar tool for managing SMB volumn in macos.<br/>
And the code is almost generate by Gemini.<br/>
You can easily check all the SMB volumn connected to your device and disconnect it.<br/>

# Funtionality

1. Add connection
>Almost the same with cmd+k in finder.

2. Favorites
>Shows the list you add, the circle on the front is status of connection.<br/>
Filled-circle means active.

3. Current connections
>Shows the active connection not in your favorite list.

4. Preference
>You can set Language and maintain your favorite list here.<br/>
Language is only supprot English and Traditional Chinese.

5. Quit
>Close this app.
