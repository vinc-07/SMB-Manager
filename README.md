# About
>This is a menu bar tool for managing SMB volumn in macos.<br/>
And the code is almost generate by Gemini.<br/>
You can easily check all the SMB volumn in your device and disconnect it.<br/>
Also can easily connect to the SMB volumn you add in favorite list.

# Funtionality

1. Add connection
>Almost the same with cmd+k in finder.

2. Favorites
>Shows the list you add, the circle on the front shows the connection status.<br/>
filled-circle means active.

3. Current connections
>Shows the active connection not in your favorite list.

4. Preference
>You can set Language and maintain your favorite list here.<br/>
Language is only supprot English and Tradition Chinese.

5. Quit
>Close this app.
